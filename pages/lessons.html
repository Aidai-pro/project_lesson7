JavaScript

Язык программирования, который делает веб-страницы интерактивными и живыми. Основа для динамических элементов и логики.

HTML

Определяет структуру и содержание веб-страницы. Базовый строительный блок, без которого невозможно существование сайта.

CSS

Отвечает за визуальное оформление: цвета, шрифты, макеты и адаптивность. Делает сайт красивым и удобным.

Node.js

Среда выполнения, позволяющая запускать JavaScript на сервере. Используется для создания бэкенда и API.
